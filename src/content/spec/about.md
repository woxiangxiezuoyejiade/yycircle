# Zhongxu / Moc

Computer Science Graduate Student

MocLab 是我的个人技术与学术空间，用来持续记录 AI Agent、AI 安全、AIGC 检测、模型溯源、RAG、记忆系统和系统评测相关的研究与工程实践。

## 我在这里记录什么

- 科研笔记：论文阅读、问题拆解、研究假设与实验计划
- 工程实践：原型系统、评测脚本、部署记录和踩坑总结
- 安全观察：AI Agent 的运行边界、记忆风险、工具调用风险与评测方法
- 项目复盘：把做过的系统和实验沉淀成可复用的经验

## 当前关注

- AI Agent Security
- AIGC Detection and Model Attribution
- RAG and Memory Systems
- AI System Evaluation
- Multimodal Content Safety
- Engineering Practice for AI Systems

## 为什么是 MocLab

我希望把博客和学术展示拆成两个互相连接的部分：

- 博客负责持续写作，记录过程、方法和实验
- Academic 页面负责正式展示研究方向、项目和个人简介

这样既能保留长期写作的灵活性，也能让网站具备更清晰的学术表达。
